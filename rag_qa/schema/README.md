# 问答数据结构

## 模块作用

`schema/` 定义检索、重排、生成和评测之间共同使用的数据格式。模块通过明确字段交换内容，而不是各自假设一个无约束字典里会有什么键。统一数据结构能减少字段名不一致，也能为来源追溯和检索过滤保留固定位置。

## Chunk 文档块

`chunk.py` 定义 `Chunk`，承载文本正文、文档标识、块标识、来源、页码、分数、父子关系及扩展元数据。文档处理阶段创建或转换 Chunk；检索器返回 Chunk；重排器更新其排序分；生成器从中取得正文并保留引用所需来源。

`to_chunk()` 等转换逻辑用于把上游文档对象归一到统一结构。新增字段时应检查转换逻辑、Milvus schema、写入代码、读取代码和前端协议，避免字段只在内存里存在却在存储时丢失。

## 引用数据

`citation.py` 定义提示词中的来源编号、文档编号、来源、页码和文本摘要。它把检索块变成 `[S1]` 等上下文编号，并删除模型输出中本轮检索结果不存在的引用。该校验只确认编号来源真实存在，不代表引用内容一定支持相邻答案陈述；流式答案也尚未做整段校验。

## 模块边界

数据结构模块只描述数据，不连接数据库、不加载模型，也不决定业务流程。它可以被多个层依赖，但不应反过来依赖 retriever、generation 或 pipeline。
